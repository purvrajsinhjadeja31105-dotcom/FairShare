📝 Project Summary

FairShare is a highly responsive, modern full-stack web portal inspired by Splitwise, designed to manage collective bills, splits, and settlements. Leveraging a real-time event-driven connection, it enables groups of friends, colleagues, or travelers to log shared expenses, vote on group administration, view synchronized updates across devices, and clear balances using payment-facilitating tools like dynamic UPI payment routing.

🧮 Core Algorithm: Greedy Debt Simplification

To streamline payments, FairShare computes group-wide balances and simplifies a complex mesh of debts (e.g., person A owing B, who owes C) into the minimum absolute number of transactions using a Greedy Matching Algorithm. It matches the largest net debtors with the largest net creditors, settling group ledgers in at most N - 1 transactions.

function simplifyDebts(balances, memberNamesMap) {
    const debtors = [];
    const creditors = [];

    // Separate members based on net owing/owed state
    for (const [userId, amount] of Object.entries(balances)) {
        const roundedAmount = Math.round(amount * 100) / 100;
        if (roundedAmount < -0.01) {
            debtors.push({ userId, balance: Math.abs(roundedAmount) });
        } else if (roundedAmount > 0.01) {
            creditors.push({ userId, balance: roundedAmount });
        }
    }

    // Sort descending by magnitude to greedy-match largest outstanding balances
    debtors.sort((a, b) => b.balance - a.balance);
    creditors.sort((a, b) => b.balance - a.balance);

    const simplifiedTransactions = [];
    let i = 0, j = 0;

    while (i < debtors.length && j < creditors.length) {
        const debtor = debtors[i];
        const creditor = creditors[j];
        const settleAmount = Math.min(debtor.balance, creditor.balance);

        simplifiedTransactions.push({
            fromUserId: debtor.userId,
            fromUserName: memberNamesMap[debtor.userId],
            toUserId: creditor.userId,
            toUserName: memberNamesMap[creditor.userId],
            amount: Math.round(settleAmount * 100) / 100
        });

        debtor.balance -= settleAmount;
        creditor.balance -= settleAmount;

        if (debtor.balance < 0.01) i++;
        if (creditor.balance < 0.01) j++;
    }
    return simplifiedTransactions;
}

Complexity Analysis: Sorting results in a Time Complexity of O(N log N), while the settlement loop executes in O(N) space and time, where N represents active group members.
